## RFI Template (Standard)

Use this template to submit a clear Request for Information (RFI) during bidding or project execution.

### Template

RFI Number: `RFI-___`  
Project Name: `__________`  
Contract Number: `__________`  
Date Submitted: `MM/DD/YYYY`  
Submitted By: `__________`  
To (COR/CO/Design Team): `__________`

Subject: `Short description of the issue`

Reference Documents:
- Drawing No(s): `__________`
- Spec Section(s): `__________`
- Detail/Sheet Reference: `__________`

Question:
`State the exact clarification needed in one precise question.`

Contractor Interpretation (if any):
`State your current interpretation to speed up response.`

Schedule/Cost Impact if Unresolved:
- Potential Schedule Impact: `___ days`
- Potential Cost Impact: `$__________`

Requested Response Date: `MM/DD/YYYY`

Attachments:
- `Photos`
- `Marked-up drawings`
- `Supporting documents`
